Pluspunkte ❤️ — PWA

Enthaltene Dateien:
- index.html            Hauptseite der App
- styles.css            Design
- app.js                Logik (Punkte zählen, speichern, Animationen)
- manifest.webmanifest  PWA-Konfiguration (Name, Icon, Startmodus)
- service-worker.js     sorgt für Offline-Funktion
- icons/                App-Icons in verschiedenen Größen

Installationsanleitung: siehe die ausführliche Schritt-für-Schritt-Anleitung
im Chat bzw. in ANLEITUNG.md.

Wichtig: Die Dateien müssen über HTTPS gehostet werden (z. B. GitHub Pages),
damit iOS die Installation "Zum Home-Bildschirm" und die Offline-Funktion
zulässt. Ein einfaches Doppelklicken der index.html auf dem PC reicht dafür
nicht aus.
